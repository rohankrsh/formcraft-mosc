# FormCraft — Drag & Drop Form Builder with Gemini AI Auto-Generation

FormCraft is a production-grade, full-stack form builder platform. It allows users to design complex forms using an intuitive drag-and-drop canvas, auto-generate complete forms from uploaded **Excel** spreadsheets and **PDF** documents using **Google Gemini Multimodal AI**, render structured data tables, and export standalone, zero-dependency offline HTML forms.

---

## 🌟 Key Features

- **🌐 Form Publishing & Dedicated Runtime System**: Publish forms to unique, collision-resistant public URLs (`/forms/:slug`) with immutable frozen version snapshots (`v1`, `v2`), pre-flight validation checklist, QR code modal, and zero builder tooling overhead in the end-user bundle.
- **📄 🤖 Multimodal AI Form Generation from PDF**: Upload any `.pdf` form or document. **Google Gemini Multimodal AI** inspects native PDF binary visual layouts, typography, input fields, checkboxes, and repeating tabular grids to auto-create an editable form schema on the canvas.
- **📊 🤖 AI & Heuristic Form Generation from Excel**: Upload any `.xlsx` or `.xls` document and let Gemini AI (or local heuristic fallback) analyze 2D visual cell layouts, section headers, dropdown options, and date/number bounds.
- **🧱 Table Palette & Predefined Cell Content Editor**: Configure table components with predefined row data, full-width section header rows (`_isHeader`), and fixed header labels (`heading`) directly from the Table Property Inspector.
- **🗑️ Form Deletion & Published Status Protection**: Administrative dashboard supports form deletion with automatic server-side status protection preventing deletion of published forms until explicitly unpublished (`400 Bad Request`).
- **📥 Static PDF Download Button**: Top-left persistent Download PDF button on all runtime forms and live previews for generating pixel-perfect `.pdf` documents using `html2canvas` and `jspdf`.
- **🎨 Interactive Drag-and-Drop Canvas**: Powered by `@dnd-kit`, allowing seamless reordering of fields, columns, and sections.
- **📐 12-Column Grid Layout System**: Every row snaps to a responsive 12-column grid system, supporting 1, 2, 3, or 4 side-by-side columns per row.
- **🗂️ Collapsible Workspace Palette**: Sidebar palette collapses from full view (`w-72`) into a sleek vertical icon tool rail (`w-14`) with hover tooltips and `Ctrl+B` / `Cmd+B` keyboard shortcut to maximize canvas workspace.
- **🔄 High-Availability 503 Retry Cascade**: Backend engine uses an automated candidate model cascade (`gemini-flash-latest` ➔ `gemini-3.5-flash` ➔ `gemini-3.6-flash` ➔ `gemini-3.8-flash` ➔ `gemini-3.7-flash`) with automatic 1.5s backoff retries to handle Google API 503 demand spikes cleanly.
- **⚠️ Ambiguity & Review Flagging (`_needsReview`)**: Complex or ambiguous layout structures are flagged with amber `⚠️ Review Needed` badges for easy inspection.
- **📄 Standalone Offline HTML Export**: Export canvas designs into single, zero-dependency `.html` files with embedded CSS, JS validation rules, and offline submission handling.
- **🌓 Light & Dark Theme Support**: Native light and dark UI modes for both the builder canvas and exported forms.
- **↩️ Complete Undo / Redo History**: Powered by `zundo` and `zustand` for step-by-step history traversal.

## 🚀 Tech Stack

### Frontend
- **Framework**: React 19 with TypeScript & Vite
- **Styling**: Tailwind CSS v4 (Vanilla CSS variables, dark mode support)
- **Drag-and-Drop**: `@dnd-kit/core`, `@dnd-kit/sortable`, `@dnd-kit/modifiers`, `@dnd-kit/utilities`
- **State Management**: Zustand v5 + Zundo v2 (`temporal` middleware for undo/redo)
- **Icons**: Lucide React Icons

### Backend & AI Engine
- **Server**: Node.js v24 + Express.js (`POST /api/forms/import/excel`, `POST /api/forms/import/pdf`)
- **FileUpload**: Multer (In-memory storage, 10MB limit, `.xlsx`, `.xls`, `.pdf` filter)
- **Multimodal PDF Engine**: `server/pdfParser.js` using inline base64 `application/pdf` binary ingestion for Gemini multimodal vision.
- **Excel Engine**: SheetJS (`xlsx`) for 2D cell grid, merge ranges (`!merges`), and data validation (`!dataValidation`) extraction in `server/geminiParser.js` & `server/excelParser.js`.
- **AI Model Cascade & Retry Engine**: Google Gemini AI (`gemini-flash-latest`, `gemini-3.5-flash`, `gemini-3.6-flash`, `gemini-3.8-flash`, `gemini-3.7-flash`) with structured JSON mode (`responseMimeType: "application/json"`) and automatic 1.5s 503 backoff retries.
- **Fallback Engine**: Local heuristic Excel & table parser for offline or fallback operation.

## 🏗️ Project Architecture & Data Schema

All forms generated by the AI or built on the canvas strictly adhere to the unified `FormDefinition` schema defined in `src/types/schema.ts`:

```typescript
export type FieldType =
  | 'text'
  | 'textarea'
  | 'number'
  | 'date'
  | 'select'
  | 'radio'
  | 'checkbox'
  | 'heading'
  | 'divider'
  | 'table'; // Structured multi-row table grid

export interface FieldOption {
  label: string;
  value: string;
}

export interface TableColumn {
  id: string;
  key?: string;
  label: string;
  type?: 'text' | 'number' | 'date' | 'select' | 'heading';
  required?: boolean;
  placeholder?: string;
  options?: FieldOption[];
}

export interface TableConfig {
  columns: TableColumn[];
  minRows?: number;
  maxRows?: number;
  allowAddRows?: boolean;
  defaultRows?: Record<string, any>[];
}

export interface ValidationRules {
  required?: boolean;
  min?: number;
  max?: number;
  minLength?: number;
  maxLength?: number;
  pattern?: string;
  customErrorMessage?: string;
}

export interface FormField {
  id: string;
  name: string;
  type: FieldType;
  label: string;
  placeholder?: string;
  helpText?: string;
  defaultValue?: string | number | boolean | string[];
  options?: FieldOption[];
  tableConfig?: TableConfig; // Configuration for 'table' type fields
  validation?: ValidationRules;
  dataBinding?: null;
  visibleIf?: { fieldId: string; equals: string | number | boolean };
  _needsReview?: boolean;
  _reviewReason?: string;
}

export interface LayoutColumn {
  id: string;
  width: number; // 1 to 12. Sum of column widths in any row MUST equal 12.
  fieldIds: string[];
}

export interface LayoutRow {
  id: string;
  columns: LayoutColumn[];
}

export interface LayoutSection {
  id: string;
  title?: string;
  description?: string;
  collapsible?: boolean;
  rows: LayoutRow[];
  _needsReview?: boolean;
  _reviewReason?: string;
}

export interface FormDefinition {
  version: '1.0.0';
  id: string;
  title: string;
  description?: string;
  settings: FormSettings;
  fields: Record<string, FormField>;
  layout: LayoutSection[];
}
```

## ⚡ How The Backend Logics Work

### 1. Multimodal Gemini PDF Import Pipeline (`server/pdfParser.js`)
1. **Binary Validation**: Reads the uploaded file buffer and verifies the `%PDF-` header signature. Corrupted or non-PDF payloads are rejected immediately with clean HTTP 400 responses.
2. **Base64 Inline Data Encoding**: Encodes the raw PDF buffer into a base64 `inlineData` structure with `mimeType: "application/pdf"`.
3. **Multimodal Spatial Vision**: Dispatches the PDF directly to Google Gemini AI. Gemini natively analyzes the document's visual layout, spatial coordinate relationships, text sizes, table grid borders, and checkbox fields.
4. **Structured JSON Mode**: Uses `responseMimeType: "application/json"` with prompt engineering that instructs Gemini to output a strict `FormDefinition` JSON object.

### 2. Gemini Excel Import Pipeline (`server/geminiParser.js`)
1. **Context Extraction**: Reads `.xlsx`/`.xls` buffers with SheetJS (`xlsx`). Extracts cell values, display strings (`w`), cell types (`t`), merged ranges (`!merges`), and validation dropdown rules (`!dataValidation`).
2. **2D Spatial ASCII Mapping**: Generates a 2D ASCII text map of the worksheet layout to give Gemini explicit visual context of merged headers, label-value alignment, and table structures.
3. **LLM Schema Compilation**: Sends the ASCII map and cell metadata to Gemini to construct the `FormDefinition`.

### 3. Structured Table & Data Grid Engine
- **Problem Solved**: Standard parsers convert repeating row data (such as invoice line items or medication entries) into dozens of fragmented, disconnected text input fields.
- **Solution**:
  - Both AI prompts (`pdfParser.js`, `geminiParser.js`) and local heuristics (`excelParser.js` via `checkRepeatingTable`) detect repeating row patterns.
  - When detected, the backend constructs a single `FormField` with `type: "table"`.
  - Column headers are mapped into `tableConfig.columns` (`id`, `key`, `label`, `type`, `required`), and initial populated entries are preserved in `tableConfig.defaultRows`.
  - On the canvas, property panel, and live preview, the table is rendered as an interactive component with live cell inputs and "+ Add Row" / trash row buttons.

### 4. High-Availability Candidate Model Cascade & 503 Retry Engine
- **Model Cascade Order**:
  1. `gemini-flash-latest` (Primary stable production model)
  2. `gemini-3.5-flash`
  3. `gemini-3.6-flash`
  4. `gemini-3.8-flash`
  5. `gemini-3.7-flash`
- **503 High-Demand Backoff**: When Google returns an HTTP 503 (`This model is currently experiencing high demand`), the engine pauses for **1.5 seconds** and retries up to 2 attempts before cascading to the next candidate model.
- **Normalizer**: The output passes through `validateAndNormalizeForm()`, which enforces 12-column row width constraints, attaches missing IDs, and validates layout integrity.

## ⚙️ Getting Started

### 1. Prerequisites
- **Node.js**: v18.0.0 or higher (v24 recommended)
- **npm**: v9.0.0 or higher

### 2. Environment Configuration
Create a `.env` file in the root directory and add your Google Gemini API key:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Installation
Install all required dependencies:

```bash
npm install
```

### 4. Running the Application
Start both the Express backend server and the Vite dev client:

```bash
# Terminal 1: Start Express Backend Server (Port 3001)
npm run server

# Terminal 2: Start Vite Dev Client (Port 5173)
npm run dev
```

Open **`http://localhost:5173/`** in your browser.

### 5. Production Build
To build the application for production:

```bash
npm run build
```

const fs = require('fs');
async function run() {
  const blob = new Blob([fs.readFileSync('test_patient_intake.pdf')], { type: 'application/pdf' });
  const body = new FormData();
  body.append('file', blob, 'test_patient_intake.pdf');

run();
